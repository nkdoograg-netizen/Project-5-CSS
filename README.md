# 🎨 CSS Basics – Practice Set Level 1

A beginner-friendly CSS practice project created to learn and practice the fundamentals of **CSS3**.

This practice set focuses on CSS selectors, different ways of applying CSS, comments, colors, and CSS priority.

---

## 📚 Topics Covered

- CSS Text Color
- ID Selector
- Class Selector
- Element Selector
- Group Selector
- Inline CSS
- Internal CSS
- External CSS
- CSS Priority

---

## 🧪 Practice Questions

### 1. Text Color

Create a heading and set its text color to **red**.

### 2. CSS Priority

Create a `div` with `id="heading"` and apply CSS using all three methods:

- Inline CSS
- Internal CSS using the `<style>` tag
- External CSS

Observe and understand the priority of different CSS methods.



### 3. CSS Selectors

Create a:

- `div`
- `paragraph`
- `heading`

Use the following selectors:

- ID Selector
- Element Selector
- Class Selector

### 4. Group Selector

Create two `div` elements with IDs:

- `first`
- `second`

Use a **Group Selector** to apply the same color to both elements.
